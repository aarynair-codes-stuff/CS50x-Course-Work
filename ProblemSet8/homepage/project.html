Student Application Helper Software


I created a website using HTML, CSS, JS, PHP, and SQL which uses an account based system with input validation. The program allows the user to plan and colour code activities on a calendar. When adding an event to the calendar, the user can tag it with skills and details about the event which would automatically create a input field for the event on the skills page where they can describe how they demonstrated that skill. Finally, all events in the calendar will be displayed on the timeline where they can reflect on it and save the timeline as a pdf.
